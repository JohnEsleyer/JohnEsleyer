The following are tools and learning projects I built for personal use and learning purposes only (This list helps me keep track of my projects easier. Feel free to view or ignore them):

- [skiff](https://github.com/JohnEsleyer/skiff) - zero-agent desktop deployment engine for low-end VPSs. Wails (Go) + React app that builds locally and ships atomic releases over plain SSH.
- [bifrost](https://github.com/JohnEsleyer/bifrost) - Zero-lag, non-interactive SSH gateway that lets AI agents run commands on a remote VPS
- [navi](https://github.com/JohnEsleyer/navi) - Navi is a cost-optimized, low-latency AI harness written in Go.
- [textify](https://github.com/JohnEsleyer/textify) - Textify is a developer tool designed to prepare your codebase for Large Language Models (LLMs) like Claude, ChatGPT, and Gemini.
- [mimiclm](https://github.com/JohnEsleyer/mimiclm) - Desktop tool for intercepting, inspecting, and mocking LLM API requests across OpenAI, Anthropic, Google Gemini, and other providers in real time.
- [keyblade](https://github.com/JohnEsleyer/keyblade) - Minimal, offline TOTP authenticator — import secrets from QR images, display QR codes, custom glassmorphic UI. Built with Wails (Go) + React.
- [lumpia](https://github.com/JohnEsleyer/lumpia) - An alternative to Remotion but it uses Raylib to render motion graphics rather than using a browser.
- [cero](https://github.com/JohnEsleyer/cero) - Cero is an offline-first, block-based markdown journal. It supports nested pages and syncs in real-time over local Wi-Fi
- [goscript](https://github.com/JohnEsleyer/goscript) - An embeddable scripting language with Go syntax, written in pure Rust, designed for game engines.
- [groot](https://github.com/JohnEsleyer/groot) - Fast-iteration 2D/3D game engine powered by wgpu and GoScript. Data-driven architecture with hot-reloadable scripts, RON prefabs, and a native plugin system.
- [HermitShell](https://github.com/JohnEsleyer/hermitshell) - Hermit provides a complete agentic OS with Docker-based agent containers, Telegram integration, and a web dashboard. Each AI agent runs in its own isolated Docker container with a dedicated workspace.
